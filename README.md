# Malfaur Engineering Products

High-End Industrial Engineering Catalogue & Web Store.

## Features
- **Dynamic Catalogue:** Fully searchable and filterable database of engineering components (Cutting Tools, Measuring Equipment, Standard Parts, Aerospace Parts, Raw Materials).
- **Dedicated Technical Details Pages:** Beautiful visual product pages featuring:
  - Clean image presentation (crisp dimensions).
  - ISO cutting material classification grid (P, M, K, N, S, H) with standard color classifications.
  - Interactive specs dropdown.
  - Paginated available dimensions & variant tables.
- **Smart Contact Integration:** Automated forms that pre-fill product details and SKU codes when navigating from variant tables.

## Tech Stack
- **Backend:** Laravel 11.x (PHP 8.2+)
- **Database:** MySQL
- **Frontend:** Vanilla CSS & JS for high performance.
